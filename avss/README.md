# AVSS — AI-Augmented Virtual Safety Simulation

김동영·조상우의 8분 발표 원고를 바탕으로 만든 **발표용 안전 훈련 브라우저 프로토타입**입니다. 컨베이어 가드, 지게차 사각지대, 화학물질 누출 의심 상황에서 행동을 선택하고, 피드백·수행 로그·다음 훈련 난이도를 확인할 수 있습니다.

## 바로 실행하기

- 웹 실행: [AVSS 시뮬레이터](https://chsh3462-byte.github.io/project/avss/)
- 소스: [chsh3462-byte/project → avss](https://github.com/chsh3462-byte/project/tree/main/avss)

오프라인 발표용 파일을 준비하려면 다음 순서를 따르세요.

1. [배포용 HTML 원본](https://raw.githubusercontent.com/chsh3462-byte/project/main/avss/index.html)을 열고 브라우저의 **다른 이름으로 저장**으로 `index.html` 파일을 저장합니다. GitHub의 [파일 화면](https://github.com/chsh3462-byte/project/blob/main/avss/index.html)에서 **Download raw file**을 눌러도 됩니다.
2. 저장한 파일을 Chrome, Edge, Firefox 등 최신 브라우저에서 엽니다.
3. 시나리오와 난이도를 선택하고 훈련을 시작합니다.
4. 각 단계에서 행동을 선택한 뒤 결과와 피드백을 확인합니다.

배포용 `index.html`에는 스타일과 스크립트가 포함되어 있어 별도 설치, 서버, API 키 없이 실행할 수 있습니다. 다운로드한 파일은 인터넷 없이도 시연할 수 있습니다.

## 발표에서 시연하는 순서

- **과제 선택:** 파일럿 사례 3종 중 하나와 훈련 난이도를 고릅니다.
- **위험 대응:** 위험 신호를 확인하고 행동을 선택합니다. 잘못된 선택에도 즉시 피드백을 받아 다시 판단할 수 있습니다.
- **지표 추적:** 선택, 반응 시간, 실수와 힌트 사용 기록을 확인합니다.
- **검토 및 재시도:** 결과와 권장 난이도를 검토하고 조건을 바꿔 다시 연습합니다.

컨베이어에서는 경보 후 접근 중지와 보고, 지게차에서는 안전선 정지·신호 확인·보행 통로 이용, 누출 의심 상황에서는 위험 인지·안전 구역 이동·보고·동료 경고를 다룹니다. 화면에 제시된 행동 순서는 **발표용 예시 규칙**입니다. 실제 사업장의 승인된 SOP나 안전 자격 평가를 대체하지 않습니다.

## 조작 방법

- 행동 선택: 버튼 클릭 또는 숫자 **1–4**. 기초는 선택지 2개, 표준은 3개, 심화는 4개입니다.
- 발표 슬라이드: **← / →** 또는 이전·다음 버튼.
- 전체 화면: **F** 또는 화면 상단의 전체 화면 버튼.
- 발표 모드에서 시뮬레이션으로 복귀: **Esc**.
- 발표 타이머는 시작·일시 정지·초기화할 수 있으며 슬라이드는 수동으로 넘깁니다.

## 구현 범위

- 선택에 따라 진행되는 3가지 시나리오와 가상 동료 피드백
- 시나리오 조건 변화, 단계별 행동 기록과 반응 시간 측정
- 실수·힌트·반응 시간을 이용한 규칙 기반 난이도 추천
- 완료한 훈련 기록의 브라우저 저장 및 CSV 내보내기
- 한영 콘텐츠와 발표자 노트를 포함한 14장 발표 모드

현재 버전의 적응형 동작은 브라우저의 **명시적인 규칙과 상태 전이**로 구현했습니다. LLM 추론이나 학습된 AI 모델은 호출하지 않으며, 헤드셋용 VR/AR, 실제 공장 센서, 외부 서버·교육 관리 시스템과 연결하지 않습니다. 원고에서 제안한 AI·VR 서비스의 핵심 사용자 흐름을 시연하는 프로토타입이며, 현장 전이 효과나 비용 절감 결과를 실증한 제품은 아닙니다.

## 기록과 개인정보

완료한 훈련 기록은 최근 200회까지 해당 브라우저의 `localStorage`에 저장합니다. 서버로 전송하거나 다른 기기와 자동 동기화하지 않습니다. 브라우저 데이터 삭제, 시크릿 모드 종료, 파일 위치 또는 접속 주소 변경 시 이전 기록을 사용할 수 없을 수 있으므로 필요한 결과는 CSV로 내려받으세요. 브라우저가 저장을 차단하는 환경에서는 현재 세션에서 시연할 수 있지만 기록이 유지되지 않을 수 있습니다.

## 8분 발표 모드

발표 모드는 훈련 시뮬레이터와 함께 사용할 수 있는 선택 기능입니다. 원고의 14장 구조, 핵심 내용, 확장 영문 대본과 한국어 설명을 담았습니다. 원문이 함께 묶은 8·9장은 섹션 인사와 현장 전이 설명으로 나눴습니다. 14장은 참고 자료이므로 발표 시간에서 제외합니다.

원고는 발표자별 4분 배분을 명시하지만, 세부 타이밍에서 Slide 7이 `03:50–04:20`으로 표기되어 교대 시점이 서로 다릅니다. 앱은 아래 **연습용 권장 배분**으로 총 8분과 각 4분을 맞췄습니다. 원문의 영문 대본은 유지했으므로 실제 말하기 속도로 리허설하며 조정하세요.

| 슬라이드 | 담당 | 권장 시간 |
| --- | --- | ---: |
| 1–7 | 김동영 | 30·35·10·50·40·45·30초 = 4분 |
| 8–13 | 조상우 | 10·45·65·50·50·20초 = 4분 |
| 14 | 참고 자료 | 시간 제외 |

발표 노트의 이미지·화면 위치 지시는 제공된 원고를 보존한 것입니다. 이 데모는 원고가 언급한 외부 이미지를 포함하지 않고 자체 그래픽을 사용하므로, 실제 발표에서는 현재 화면에 맞춰 지시어를 바꿔 읽으세요.

## GitHub 배포 구조

이 앱은 기존 `chsh3462-byte/project` 저장소의 **`avss/` 하위 폴더**에 배치합니다. 기존 GitHub Pages 설정인 `main` 브랜치의 `/(root)`를 사용하며, 앱 주소는 다음과 같습니다.

<https://chsh3462-byte.github.io/project/avss/>

저장소 루트의 기존 페이지를 대체하지 않습니다. `avss/index.html`을 갱신해 `main`에 반영하면 기존 Pages 배포 과정에서 해당 경로도 갱신됩니다. GitHub의 Pages 빌드가 완료될 때까지 이전 버전이 잠시 표시될 수 있습니다.

## 수정·재생성·검증

소스는 `src/`에 나누어 관리하고, `build.py`가 스타일과 스크립트를 하나의 HTML로 합칩니다. `avss/` 디렉터리에서 실행합니다.

```sh
python build.py
node --test tests/engine.test.cjs
```

Python 실행 명령이 `python3`인 환경에서는 `python3 build.py`를 사용합니다. 빌드 결과는 `index.html`과 `dist/index.html`입니다. GitHub Pages는 `avss/index.html`을 사용하므로 수정한 소스와 재생성한 HTML을 함께 반영하세요.

검증에는 Node의 시나리오 엔진 테스트와 jsdom 기반 UI 동작 검사를 사용했습니다. 시나리오 진행·오답·힌트·반응 시간·난이도 추천과 주요 화면 동작을 검사하지만, jsdom은 실제 브라우저나 Canvas 렌더러가 아닙니다. 작업 환경에 관리형 CUA 브라우저 도구가 없어 **실제 브라우저의 화면·Canvas·전체 화면 동작은 QA하지 못했습니다**. 발표에 사용할 브라우저에서 파일을 열어 화면 크기와 조작을 미리 확인하세요.

## 전체 자동 점검

개발자용 DOM 통합 테스트는 `npm install` 후 `npm test`로 실행합니다. 실제 페이지 사용과 HTML 열기에는 npm이나 Node가 필요하지 않습니다. Canvas 검사는 좌표·상태·입력 연결을 모의 환경에서 검증하며 실제 화면 렌더링 확인을 대체하지 않습니다.
